🛒 ECOMZY — MERN E-Commerce Application

A full-stack e-commerce web application built using the MERN stack (MongoDB, Express, React, Node.js) with Redux Toolkit for state management, JWT authentication, Cloudinary image uploads, PayPal payments, and a fully responsive UI powered by Tailwind CSS.
This project is designed to simulate a real-world production e-commerce platform.

🧾 Key Features
Frontend

⚛️ React + Vite (or CRA)

🎛️ State management using Redux Toolkit + Thunk

🧾 Product listing, search, filtering

🛍️ Cart management

🧑‍💼 User login & registration (JWT)

📦 Order placement and order history

💳 PayPal payment integration

🎨 Fully responsive UI with Tailwind CSS

🔒 Protected routes for users/admin

Backend

🟢 Node.js + Express REST API

🗄️ MongoDB + Mongoose models (Users, Products, Orders)

🔐 Secure JWT Authentication & Authorization

📤 Image uploads using Cloudinary

💰 PayPal payment gateway integration

🛡️ Middleware for error handling & route protection

📦 Modular folder structure (controllers, routes, config)
